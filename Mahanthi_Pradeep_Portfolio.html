Prompt Engineering

How I structure prompts to make Generative AI outputs more accurate, useful and consistent.

1. Role + Context Prompting

Give the model a clear role and enough project context before asking for an output.

Act as an AI interview coach. Context: The user is preparing for a Java developer interview. Task: Create 10 questions from beginner to advanced. Constraint: Give a short answer key for each.

2. Structured Output

Define the exact format so the result can be used directly inside an application.

Return the career recommendations using: 1. Skill gap 2. Suggested learning topic 3. Project idea 4. Expected outcome

3. Few-Shot Examples

Provide examples to demonstrate the desired style or classification pattern.

Example: Input: Python + SQL → Backend Developer Now classify: Input: Python + ML + Statistics → ?

4. Constraints & Iteration

Set boundaries, review the output and refine the prompt for better results.

Rewrite the response in simple student-friendly language. Maximum: 120 words. Use bullet points. Avoid unnecessary technical jargon.
